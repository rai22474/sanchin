# 0017 — sanchin is written in English

[README](../../README.md) · [Decisions](index.md)

**Status:** accepted (2026-10-31)

## Decision
Code, skills, docs and templates are in English. A project's artifacts use
the project's language and terms, declared in its adapter.

## Why
A plugin meant for any project needs the widest common language; each
project keeps its own words where its people read them.
