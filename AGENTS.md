# Working on Sanchin

Sanchin shares its process between Claude Code and Codex. Start at
[docs/index.md](docs/index.md) for the process and [docs/codex.md](docs/codex.md)
for Codex installation and runtime conventions. The source skills live
in [skills/](skills/).

In this repository `scripts/sanchin` is the validator. In consuming
projects it is a wrapper generated from [templates/sanchin](templates/sanchin).
